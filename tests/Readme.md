## what this does
- from frontend take 3 inputs
- send 3 inputs to backend
- save in db
## frontend
- in MyInputForm component we take input from user
- set it in state
- send it to backend via axios
## backend
- in backend we have 3 layers
- controller takes input
- passes it service
- service creates a modal
- saves it to db
